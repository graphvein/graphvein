# Graphvein v0.1.0

<!-- The release workflow uses this file as the release notes of the tag
v0.1.0, so links are absolute. -->

The first public release of Graphvein: a local tool that maps a codebase
from its architecture overview down to the exact function or line, and
labels every fact with how it was found.

Graphvein has been developed in the maintainer's own repository since
October 2026. This public repository starts from a snapshot of that work,
so its history begins here; development continues in the open from this
release on.

## What is in it

- `graphvein index` builds the index of a repository; `graphvein serve`
  opens a local web UI on it (loopback only) with the sections API (routes
  and their callers), Changes (what a change reaches), Architecture,
  Schema, Explorer (API documentation and a guarded "Try it out"), Project
  and What Graphvein couldn't read. See the
  [status](https://github.com/graphvein/graphvein/blob/v0.1.0/README.md#status) and the [guide](https://github.com/graphvein/graphvein/blob/v0.1.0/docs/guide/1-start-here.md).
- Several repositories, for example a frontend and a backend, can be
  indexed and served as one project, with calls in one linked to routes
  in another ([project](https://github.com/graphvein/graphvein/blob/v0.1.0/docs/cli/project.md)).
- `graphvein mcp` is a read-only MCP server over the same index for coding
  agents ([mcp](https://github.com/graphvein/graphvein/blob/v0.1.0/docs/cli/mcp.md)).
- What each area reads, and the measured evidence behind it, is in the
  README's [status table](https://github.com/graphvein/graphvein/blob/v0.1.0/README.md#status) and on the evidence
  pages: [link precision](https://github.com/graphvein/graphvein/blob/v0.1.0/docs/evidence/link-precision.md),
  [call binding](https://github.com/graphvein/graphvein/blob/v0.1.0/docs/evidence/call-binding.md) and the
  [MCP benchmark](https://github.com/graphvein/graphvein/blob/v0.1.0/docs/evidence/benchmark/README.md).

## Install

Download the archive for your system and `SHA256SUMS` below, check the
checksum and the build provenance, and allow the first run on Windows or
macOS as the README's [Install](https://github.com/graphvein/graphvein/blob/v0.1.0/README.md#install) section
describes; the binaries are not code-signed. Installing with
`go install github.com/graphvein/graphvein/cmd/graphvein@v0.1.0` builds
the binary yourself and shows neither warning.

## Known gaps

Graphvein lists what it does not see instead of guessing. What it does not
see or model in this release is in [known gaps](https://github.com/graphvein/graphvein/blob/v0.1.0/docs/known-gaps.md); a call
it cannot link is counted as unmatched, dynamic or behind a wrapper, not
hidden.

## Reporting problems

A fact Graphvein shows that is not true is the most important kind of
bug: report it with the
[Wrong fact](https://github.com/graphvein/graphvein/issues/new?template=wrong-fact.yml)
issue form. Contributions are
welcome under the contributor licence agreement
([CONTRIBUTING.md](https://github.com/graphvein/graphvein/blob/v0.1.0/CONTRIBUTING.md)); report vulnerabilities
privately as [SECURITY.md](https://github.com/graphvein/graphvein/blob/v0.1.0/SECURITY.md) describes.
