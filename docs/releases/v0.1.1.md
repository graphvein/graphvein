# Graphvein v0.1.1

<!-- The release workflow uses this file as the release notes of the tag
v0.1.1, so links are absolute. -->

A small update to v0.1.0, mainly for the first run.

## Changed

- Running `graphvein` with no arguments now opens the web UI on every platform, whether you double-click it or type it in a terminal: it serves the workspace view on 127.0.0.1:7420 and opens your browser there, where you can add a repository. Before, a double-clicked `graphvein.exe` on Windows printed the usage and closed at once. Over SSH or without a desktop it prints the address instead. If Graphvein already runs on 7420 it opens that one; if another program holds the port it uses the next free one up to 7430. `graphvein help` lists the commands as before ([serve](https://github.com/graphvein/graphvein/blob/v0.1.1/docs/cli/serve.md)).
- `graphvein help` lists the `query`, `callers` and `impact` commands, which answer the same questions as the web UI from the command line, with `--json` for scripts ([queries](https://github.com/graphvein/graphvein/blob/v0.1.1/docs/cli/queries.md)).

## Fixed

- The benchmark results page no longer names a public commit for the build its runs used; that build predates the public history.
- Release notes like these render as paragraphs on GitHub.

The full list is in the [changelog](https://github.com/graphvein/graphvein/blob/v0.1.1/CHANGELOG.md). Install, checksums, provenance and the first-run steps for Windows and macOS are unchanged; see the README's [Install](https://github.com/graphvein/graphvein/blob/v0.1.1/README.md#install) section.
