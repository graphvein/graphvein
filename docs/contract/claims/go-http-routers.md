# Claim contract: Go HTTP routers

The claim contract of the Go HTTP router extractor and linker (ADR 0076) as recorded when
it was designed (task T023, internal record). `docs/extract/routes.md` (Go claim contract) and the
code table in `internal/extract/routes` must equal these rows (`TestGoRoutesContract`).

## Claim contract (draft)

Row kinds: **K** recognition and scope; **O** router objects; **R**
registrations; **P** patterns; **C** composition; **H** handlers and
attributes; **V** assumptions (above, no branch); **D** the single default
branch. The implementation contract test keeps this table, the Go table in
`internal/extract/routes` (file `gohttp_contract.go`) and
`docs/extract/routes.md`'s new Go section 1:1, checks one tagged branch
per claim row, and checks that the fixture reaches every row, every
listed form of a multi-form row and every D form. **32 rows: 31 rows
plus D** (GR-V counted as one, as GO-V in T018g5; GR-K4 and the
`escaped_router` refusal of GR-C4 were added as reported
contract changes; GR-C6 and assumption GR-V5, on the
decision on GR3's open points; GR-O7, the `srv.Handler =
h` form of GR-C6 and the plain-handler exception of GR-C3,
on developer decision GO1; GR-G1 and GR-C4's method-chain refusal, on developer decision GO2).
