# Claim contract: Sequelize models

The environment assumptions and claim contract of the Sequelize model extractor (ADR
0061) as recorded when it was designed (task T018g3, internal record).
`docs/extract/schema-sequelize.md` and the code table in
`internal/extract/models/sequelize` must equal them (`TestSequelizeContract`).

## Environment (assumptions, part of the contract)

- **SQ-V1 Pins.** The `sequelize` and `inflection` versions in the
  package's lockfile are the ones that created the database
  (`pins: {"sequelize": "<v>", "inflection": "<v>"}`).
- **SQ-V2 Schema deployed.** The database was created by the models'
  `sync` or by migrations that match the models (sequelize-cli or umzug
  migrations are not read). Gladys never calls `sync` (umzug migrations
  only); opencollective-api calls it in a dev setup script only.
- **SQ-V3 Models load.** Module side effects do not change the models
  beyond what is read, and values the rules do not read (ENUM label lists
  from imported constants) are valid on the dialect.
- **SQ-V4 Dialect.** The database is of the instance's literal `dialect`,
  or of the dialect the package's single installed Sequelize driver
  implies (open point O3).
- **SQ-V5 Global define.** The instance has no `define` options beyond the
  ones read (open point O1).
- **SQ-V6 Mapped dialects.** MySQL, MariaDB and MSSQL facts follow
  Sequelize's query generator as its source states at the pinned version
  (never `oracle`).

## Claim contract

Finalised from the inventory and the oracle (the investigation). Row kinds: **K**
scope and naming; **M** model forms; **A** attributes; **O** model
options; **R** associations; **P** provable failures; **U** unread tool
folders; **V** assumptions; **D** the single default branch. Every form
the corpora use has exactly one row (counts per row:
the T018g3 inventory (internal record)); forms only the fixture uses come from
the same oracle runs (scratch probes). The contract test keeps
`docs/extract/schema-sequelize.md`, the Go table and the code 1:1 (plan,
shared piece 4). **15 rows: 14 rows plus D**; SQ-P1 only refuses, SQ-U1
only marks, SQ-V has no branch.

Dialect rule (developer decision 2026-11-13):
- **postgres:** facts verified by the oracle (`verification: "oracle"`):
  `sync` on a scratch Postgres 17, catalog read.
- **sqlite:** the same oracle on a scratch SQLite file (`sqlite_master`,
  `pragma table_xinfo`, `index_list`, `index_info`, `foreign_key_list`).
- **mysql, mariadb, mssql:** facts from Sequelize 6.37.8's
  `lib/data-types.js`, `lib/dialects/<dialect>/data-types.js` and
  `lib/dialects/<dialect>/query-generator.js` (`attributeToSQL`,
  `createTableQuery`), with file:line in `docs/extract/schema-sequelize.md`:
  `verification: "mapped"`, SQ-V6. Constructing a Sequelize instance for
  these dialects needs their driver package, which this task does not
  install, so there is no rendered reference.
- **Unknown in every dialect:** constraint names the database chooses
  (Postgres `<table>_<column>_key`, `_fkey`, `_pkey`; SQLite
  `sqlite_autoindex_*`), collations, sequences' options.

Provider-independent facts (table and column names, column set, primary
key columns, foreign-key target table and columns) are claimed for every
supported dialect with the dialect's verification.
