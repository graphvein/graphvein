# Claim contract: code-to-table access

The claim contract of the code-to-table extractor (ADR 0060) as recorded when it was
designed (task T018h, internal record). `docs/extract/table-access.md` and the code
table in `internal/extract/tableaccess` must equal these rows (`TestTableAccessContract`).

## Claim contract

Row kinds: **P** Python (SQLModel/SQLAlchemy), **R** Prisma, **Z**
Drizzle, **S** sqlx, **Q** the SQL subset reader shared by every SQL
carrier, **D** the single default branch. Every form the corpora use has
exactly one row (counts per row: the T018h inventory (internal record)); CT-S2
and CT-P2's `insert` are fixture-only. The contract test keeps
`docs/extract/table-access.md`, the Go table and the code 1:1 (T018
plan, shared piece 4: Go table equals the docs table, a branch per claim
row and a row per branch, the tags emitted over the fixtures equal the
claim rows, each listed form of a multi-form row reached). **17 rows: 16
rows plus D**; CT-Q1 and CT-Q2 are reached through the SQL carriers
(P5, R3, Z4, S1, S2) and tagged alongside them.
