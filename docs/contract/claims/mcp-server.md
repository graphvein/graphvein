# Claim contract: MCP server

The claim contract of the read-only MCP server (`graphvein mcp`, ADR 0082):
what each tool and each part of the response envelope may state, which
existing read path it comes from, and when it must refuse or say unknown.
`internal/mcp` keeps its row table (`claimRows`, `internal/mcp/claims.go`)
1:1 with the table below (`TestClaimContract`), and the session goldens
(`TestSessionGoldens`, `internal/mcp/testdata/session-*.golden.json`) reach
every row.

Every tool reuses an existing read path: `internal/query` for `find`,
`callers` and `impact` in one repository, the HTTP API v0 views
(`server.Reader`, the same handlers `graphvein serve` registers, without a
listener) for the rest and for project mode, and `internal/changes` for the
table access entries and the sites that may also use a table. The MCP layer
adds no rule of its own about the code; it maps the answers into one
envelope and keeps their labels. Rows MC-33 to MC-99 are free for later
tools.

## Envelope

Every tool answers with one object (`structuredContent`, and by default
the same minified JSON as the one text block):

`tool`, `envelope` (1), `repository` or `project`, `error` on a refusal
(`isError: true`), `freshness`, `request`, `bounds`, `page`, `summary`,
`results`, `unknowns`, `assumptions`, `labels` and `omitted` (each entry
`{field, how}`: what was left out and how to get it), in that order, so a
client that cuts a long text still has the refusal, the caps that bound
and the paging. Lists are always present: an empty list means the reused
code reported nothing of that kind, never that nothing exists. A list an
unknown carries (possibly missing call sites, sites that may also use a
table, external stubs, not-proven entries, blind spots) is
`{items, total, more, next_cursor}`: on the tools that take
`unknowns_limit` (default 20, at most 500) and `unknowns_cursor`, at most
that many items with the exact total; the rest by cursor.

## Encoding

A tool result carries the envelope as `structuredContent` (with an
`outputSchema` naming the envelope's fields) and, by default, the same
minified JSON as its single text block, as the MCP specification advises
for clients that read only text. `graphvein mcp --structured-only` replaces
the text copy with a one-line summary that names the first bound cap or
the error first; the envelope is built in one place, so the choice per
client changes no claim.
