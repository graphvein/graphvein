# Keyboard shortcuts

`?`, `[`, `/` and `o` do nothing while you type in a field or an editor.

| Keys | What they do |
|---|---|
| `?` | Open this Help page |
| `Ctrl+K` or `Cmd+K` | Jump to a route, operation, table, symbol or file |
| `[` | Collapse the sidebar to its icons, or expand it again (remembered in this browser) |
| `↑` `↓` `PgUp` `PgDn` `Home` `End` | Move through the route list or the table list |
| `↑` `↓` | Move between caller rows; an open code peek follows |
| `Enter` | On a caller row, open or close its code peek |
| `Esc` | Close the code peek |
| `/` | Schema: go to the table filter |
| `o` | Schema: open the selected table in your editor |
| `←` `→` `Home` `End` | Move between tabs in Schema and Changes |
